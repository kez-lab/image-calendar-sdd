# Raw Design Sources

`raw/design/`은 디자인 산출물 원본을 보관하는 영역이다.

규칙:

- 디자인 원본은 가능한 한 수정하지 않고 보관한다.
- 디자인에 대한 해석, 채택 여부, 수정 요청은 `wiki/02-design/`에 기록한다.
- 구현에 반영할 디자인 결정은 design wiki를 거쳐 specs로 내려간다.
