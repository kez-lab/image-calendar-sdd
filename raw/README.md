# Raw Sources

`raw/`는 프로젝트의 원천 자료 보관소다.

규칙:

- 원천 자료는 가능한 한 원문 그대로 보관한다.
- LLM은 사용자의 명시 요청 없이 기존 raw source를 수정하지 않는다.
- 요약, 해석, 결정, 정규화된 요구사항은 `wiki/`에 작성한다.
- 이미지, 디자인 산출물, 회의록, 프롬프트, 리서치 문서는 모두 `raw/sources/` 또는 하위 폴더에 추가한다.
