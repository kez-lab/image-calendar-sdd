# Meeting Brief: Product Planning Kickoff

Date: 2026-04-28  
Topic: 로컬 전용 개인 이미지 캘린더 MVP 기획 고도화  
Facilitator: Codex

## Purpose

현재 PRD와 MVP 범위를 바탕으로, 실제 출시 가능한 MVP 기획으로 고도화한다. 특히 “서버 없는 로컬 개인 기록 앱”이라는 제품 방향을 사용자 가치, 첫 사용 경험, 기록 루틴, 아카이브, 데이터 안전 측면에서 검토한다.

## Product Invariants

- 서버 없음
- 로그인 없음
- 친구 공유 없음
- 공개 피드 없음
- 모든 데이터는 사용자 디바이스 로컬 저장
- 사용자가 외부 업로드를 오해하지 않아야 함
- 기록 작성은 30초 안에 끝나야 함

## Questions To Decide

- MVP의 핵심 사용자 약속을 한 문장으로 어떻게 정의할 것인가?
- 온보딩에서 로컬 저장 가치를 얼마나 전면에 둘 것인가?
- 기록 작성의 최소 필수 입력은 무엇인가?
- 아카이브 기본 구조는 월별 보기인가 리스트 보기인가?
- 백업/복원은 MVP에서 실제 기능인가, 설정 화면의 안내/진입점인가?
- 소셜 없이 재방문을 유도하는 핵심 루틴은 무엇인가?
