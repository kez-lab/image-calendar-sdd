# Claude Design Prompt: Local Image Calendar

Source type: user-provided design prompt  
Imported: 2026-04-27  
Status: active source

모바일 앱 디자인을 만들어줘.

## 프로젝트 개요

이 앱은 사용자가 자신의 하루를 사진으로 기록하고, 날짜별 캘린더에서 다시 볼 수 있는 개인용 이미지 캘린더 앱이야.
SNS 기능은 없고, 친구 공유도 없으며, 오직 나만 사용하는 프라이빗 기록 앱이야.
서버 없이 동작하는 구조를 전제로 하며, 모든 데이터는 사용자의 디바이스 로컬에 저장돼.
즉, 로그인 없이도 사용할 수 있고, 사진, 메모, 감정 태그를 날짜별로 기록하고 다시 볼 수 있는 앱이야.

## 핵심 컨셉

“내 하루의 이미지를 캘린더 위에 조용히 쌓아가는 개인 기록 앱”

## 중요한 조건

- 서버 없음
- 로그인 없음
- 친구 공유 없음
- 모든 데이터는 디바이스 로컬 저장
- 사진, 메모, 감정 태그를 날짜별로 기록
- 사용자가 ‘외부로 업로드된다’고 오해하지 않도록 UI에서 로컬 저장 구조를 명확하게 전달
- MVP 수준이지만 실제 서비스처럼 완성도 있게 디자인

## 타깃 사용자

- 하루를 사진으로 기록하고 싶은 사람
- 공개형 SNS는 부담스럽지만 개인 기록은 하고 싶은 사람
- 사진첩보다 날짜별 정리가 잘 되는 구조를 원하는 사람
- 감성적인 다이어리 앱을 좋아하지만 복잡한 기능은 원하지 않는 20대 사용자

## 플랫폼

- 모바일 앱 기준
- iPhone 15 Pro 크기를 우선 기준으로 디자인
- iOS 스타일을 기본으로 하되, Android에서도 무리 없이 적용 가능한 깔끔한 UI
- 세로형 화면 중심

## 디자인 톤앤매너

- 따뜻하고 조용한 분위기
- 감성적이지만 과하게 꾸미지 않은 미니멀 UI
- 부드러운 아이보리, 라이트 그레이, 연한 블루 또는 라벤더 계열 컬러
- 둥근 카드, 적당한 여백, 부드러운 그림자
- 사진이 주인공이 되도록 UI는 단정하고 차분하게 구성
- 다이어리 느낌은 살리되, 정보 구조가 흐려지지 않게 구성

## 핵심 사용자 가치

- 사진과 메모를 날짜별로 쉽고 빠르게 기록할 수 있다.
- 캘린더에서 기록 유무를 한눈에 볼 수 있다.
- 과거의 하루를 다시 찾기 쉽다.
- 서버 없이 내 폰 안에서만 안전하게 보관된다는 신뢰감을 준다.

## 주요 화면

### 1. 온보딩 화면

- 3장의 온보딩 화면으로 구성
- “하루를 사진으로 기록하세요”
- “날짜별로 캘린더에 정리하세요”
- “내 폰에만 저장되는 프라이빗 기록”
- 마지막 화면에는 시작하기 버튼
- 전체적으로 따뜻하고 직관적인 첫인상

### 2. 홈 / 월간 캘린더 화면

- 월간 캘린더 중심 레이아웃
- 기록이 있는 날짜는 작은 이미지 썸네일 또는 점 표시
- 오늘 날짜는 강조
- 상단에는 월 이동, 검색, 설정 아이콘
- 하단에는 탭바 또는 Floating Add Button
- 사용자가 이 화면에서 기록 여부를 빠르게 파악할 수 있어야 함

### 3. 날짜별 기록 상세 화면

- 선택한 날짜의 기록을 볼 수 있는 화면
- 사진 여러 장을 카드형으로 표시
- 각 카드에는 사진, 짧은 메모, 감정 태그 포함
- 같은 날짜에 기록이 여러 개 있을 수 있게 구성
- 수정, 삭제 기능 제공
- 비어 있는 날짜라면 “아직 기록이 없어요” 같은 빈 상태 UI 제공

### 4. 기록 추가 화면

- 사진 추가 방식: 카메라 촬영 또는 갤러리 선택
- 날짜 선택
- 짧은 메모 입력
- 감정 태그 선택
- 저장 버튼
- 입력 과정은 최대한 단순하고 빠르게
- 30초 안에 기록을 끝낼 수 있는 흐름으로 설계

### 5. 아카이브 화면

- 저장한 기록을 모아볼 수 있는 화면
- 월별 보기 또는 리스트 보기
- 감정 태그 필터
- 검색 기능
- 오래된 기록도 쉽게 찾을 수 있도록 구조화
- 이미지 중심으로 보이되 탐색성이 좋아야 함

### 6. 설정 화면

- 로컬 저장 안내
- 데이터 내보내기 버튼
- 데이터 가져오기 버튼
- 전체 데이터 삭제 버튼
- 앱 정보
- “이 기록은 현재 디바이스에만 저장됩니다” 문구를 명확히 표시
- 백업/복원 UX가 너무 기술적으로 보이지 않도록 친절하게 설계

## 필수 UX 원칙

- 사용자가 서버 업로드나 외부 공유를 절대 오해하지 않게 한다.
- 로컬 저장 상태를 분명하게 보여준다.
- 기록 작성 흐름은 짧고 직관적이어야 한다.
- 날짜별 탐색이 쉬워야 한다.
- 감성은 유지하되 사용성이 먼저 드러나야 한다.
- 삭제, 백업, 복원은 명확하고 안전하게 느껴져야 한다.
- 접근성을 고려해 버튼 크기, 텍스트 대비, 터치 영역을 충분히 확보한다.

## 주요 컴포넌트

- 월간 캘린더
- 날짜 셀 썸네일
- 이미지 카드
- 감정 태그 칩
- 메모 입력 필드
- Floating Action Button
- 검색바
- 빈 상태 UI
- 로컬 저장 안내 배지
- 백업/복원 버튼
- 삭제 확인 모달

## 탭 구조

1. Calendar
2. Add
3. Archive
4. Settings

## 원하는 결과물

- 모바일 앱 주요 화면 6개를 한 번에 보여준다.
- 실제 앱 서비스 제안서처럼 완성도 높은 UI로 구성한다.
- 화면 간 흐름이 자연스럽게 이어지도록 배치한다.
- MVP 수준으로 단순하지만, 실제 출시 가능한 느낌이 들게 한다.
- SNS 기능, 좋아요, 댓글, 팔로우, 공개 피드는 넣지 않는다.
