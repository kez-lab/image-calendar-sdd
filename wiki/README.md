# LLM Wiki

이 wiki는 프로젝트의 영속성 세컨 브레인이다. LLM이 원천 자료를 읽고 구조화한 결과를 유지하며, 이후 SDD와 구현의 기준 문서로 사용한다.

시작할 때 읽을 파일:

1. [index.md](index.md)
2. [00-context/current-state.md](00-context/current-state.md)
3. [00-context/open-questions.md](00-context/open-questions.md)
4. [07-llm/context-loading-guide.md](07-llm/context-loading-guide.md)

주요 원칙:

- raw source는 보존하고, 해석과 합의는 wiki에 기록한다.
- wiki는 항상 현재 프로젝트 이해를 반영한다.
- 기능 구현은 wiki → specs → tasks → code 순서로 진행한다.
- 중요한 결정은 [06-project/decision-log.md](06-project/decision-log.md)에 남긴다.
- 회의 원문은 `raw/meetings/`에 보관하고, 회의록은 [08-meetings](08-meetings/README.md)에 남긴다.
