# MVP Scope

## Included

- 3장 온보딩
- 첫 기록 만들기 CTA
- 월간 캘린더 홈
- 기록이 있는 날짜 점/미니 스택 표시
- 날짜별 기록 상세
- 카메라 촬영 또는 갤러리 선택 진입점
- 사진 추가
- 날짜 선택
- 선택형 짧은 메모 입력
- 고정 목록 기반 선택형 감정 태그
- 기록 수정/삭제
- 빈 상태 UI
- 아카이브 최근 월 우선 월별 그룹 보기
- 감정 태그 필터
- 검색 기능
- 설정 화면
- 로컬 저장 안내
- 백업 파일 내보내기
- 데이터 가져오기/복원 안내 또는 후속 진입점
- 전체 데이터 삭제 버튼과 확인 모달
- 하단 탭바: Calendar, Add, Archive, Settings
- Calendar compact local-storage badge
- 저장 후 Day Detail 이동

## Explicitly Excluded

- 서버 저장
- 로그인/회원가입
- 친구 공유
- 공개 피드
- 팔로우
- 좋아요
- 댓글
- 추천 알고리즘
- 실시간 동기화

## MVP Quality Bar

- 사용자가 외부 업로드가 있다고 오해하면 MVP 미완성으로 본다.
- 기록 작성 플로우가 길거나 복잡하면 MVP 미완성으로 본다.
- 캘린더에서 날짜별 기록을 찾기 어렵다면 MVP 미완성으로 본다.
- 삭제/백업/복원 설명이 불명확하면 MVP 미완성으로 본다.

## Deferred

- 클라우드 백업
- 다중 디바이스 동기화
- 고급 통계
- 위젯
- 지도/위치 기반 탐색
- 자동 추억 생성
- 사진 OCR 검색
- 실제 데이터 가져오기/복원
- 감정 태그 사용자 정의
- 기본 사진 품질 설정
- 한 주 시작 요일 설정
