# User Flows

## First Run

1. 사용자가 앱을 연다.
2. 온보딩에서 핵심 가치 3가지를 본다.
3. 마지막 화면에서 `첫 기록 만들기`를 누른다.
4. Add 화면으로 진입한다.
5. 사용자는 원하면 `건너뛰고 캘린더 보기`를 선택할 수 있다.

Core message:

- 하루를 사진으로 기록하세요.
- 날짜별로 캘린더에 정리하세요.
- 내 폰에만 저장되는 프라이빗 기록.

## Create Record

1. 사용자가 Calendar 또는 Add 탭에서 기록 추가를 시작한다.
2. 카메라 촬영 또는 갤러리 선택을 고른다.
3. 날짜를 확인하거나 변경한다.
4. 선택적으로 짧은 메모를 입력한다.
5. 선택적으로 고정 감정 태그를 선택한다.
6. 저장한다.
7. 기록은 해당 날짜의 상세 화면과 캘린더에 반영된다.

## Review Day Record

1. 사용자가 캘린더에서 기록이 있는 날짜를 선택한다.
2. 해당 날짜의 사진 카드 목록을 본다.
3. 같은 날짜의 기록을 생성 시간 오름차순으로 본다.
4. 각 카드에서 사진, 메모, 감정 태그를 확인한다.
5. 필요하면 수정 또는 삭제를 실행한다.

## Explore Archive

1. 사용자가 Archive 탭을 연다.
2. 최근 월 우선의 월별 그룹으로 기록을 탐색한다.
3. 감정 태그 필터나 검색을 사용한다.
4. 원하는 기록을 선택해 상세로 이동한다.

## Manage Local Data

1. 사용자가 Settings 탭을 연다.
2. 로컬 저장 안내를 확인한다.
3. 백업 파일 내보내기를 선택한다.
4. 전체 데이터 삭제 시 확인 모달을 거친다.
