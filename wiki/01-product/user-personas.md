# User Personas

## Daily Photo Keeper

Primary MVP target.

하루에 1-3장의 사진을 남기고 싶지만 복잡한 글쓰기나 공개 게시가 부담스러운 사용자.

Needs:

- 빠른 사진 기록
- 선택형 짧은 메모와 감정 태그
- 날짜별 정리

## Private Diary User

감성적인 다이어리 앱은 좋아하지만 개인 기록이 외부로 나가는 것에 민감한 사용자.

Needs:

- 서버 없음에 대한 명확한 안내
- 로그인 없는 시작
- 로컬 저장 신뢰감

## Calendar Memory Finder

과거 사진을 날짜별로 다시 찾고 싶은 사용자.

Needs:

- 월간 캘린더 중심 탐색
- 아카이브 검색
- 감정 태그 필터
- 오래된 기록 탐색성
