# Design Principles

## Tone

- Warm
- Quiet
- Private
- Minimal
- Organized

## Visual Rules

- 사진과 날짜가 정보 구조의 중심이어야 한다.
- 장식보다 기록 유무, 날짜, 메모, 감정 태그가 먼저 이해되어야 한다.
- 로컬 저장 안내는 신뢰감을 주되 과도하게 기술적으로 보이면 안 된다.
- 카드, 칩, 배지는 부드럽지만 명확해야 한다.
- 빈 화면도 불안하지 않고 개인 공간처럼 느껴져야 한다.

## Interaction Rules

- 기록 작성 플로우는 한 화면 안에서 가능한 한 끝낸다.
- 카메라 촬영과 갤러리 선택 진입점을 명확히 제공한다.
- 날짜 선택은 기본값을 오늘로 두되 쉽게 변경 가능해야 한다.
- 사진은 필수 입력이고 메모와 감정 태그는 선택 입력으로 느껴져야 한다.
- 온보딩 후 첫 기록 만들기 CTA를 제공하되, 건너뛰고 Calendar를 볼 수 있어야 한다.
- 삭제는 즉시 실행하지 말고 확인 모달을 제공한다.
- 백업/복원은 사용자가 결과를 이해한 뒤 실행하게 한다.

## Anti-Patterns

- 업로드, 동기화, 클라우드처럼 서버 저장을 암시하는 문구
- 공개 게시처럼 보이는 CTA
- 무한 피드 중심 홈
- 좋아요, 댓글, 팔로우 요소
- 감성 문구가 정보 구조를 가리는 레이아웃
- 전체 데이터 삭제가 가볍게 보이는 UI
- 작은 월간 캘린더 셀에 과도한 사진 썸네일을 넣어 날짜 가독성을 해치는 UI
