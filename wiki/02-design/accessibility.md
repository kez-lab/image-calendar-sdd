# Accessibility

## Text Contrast

- 본문 텍스트는 배경 대비가 충분해야 한다.
- 연한 블루/라벤더는 장식 배경이나 보조 요소로 우선 사용하고, 핵심 텍스트에는 저대비 색을 피한다.
- 로컬 저장 안내와 삭제 경고는 작은 보조 텍스트만으로 처리하지 않는다.

## Touch Targets

- 주요 버튼과 탭은 모바일 표준 터치 영역을 만족해야 한다.
- 감정 태그 칩과 삭제/수정 버튼은 오동작이 적을 만큼 충분한 크기여야 한다.
- 전체 데이터 삭제 버튼은 실수 탭을 줄이도록 위치와 확인 과정을 설계한다.

## Privacy Clarity

- 로컬 저장 상태는 색만으로 표현하지 않는다.
- `내 폰에만 저장됨` 같은 텍스트를 포함한다.
- 내보내기/가져오기/삭제는 스크린 리더에서도 결과가 이해되는 문구를 제공한다.

## Motion

- MVP에서는 필수 정보 인지를 방해하는 과한 애니메이션을 피한다.
- 기록 저장, 삭제, 복원 상태 전환은 부드럽게 하되 결과를 명확히 보여준다.
