# Glossary

## Day Record

특정 날짜에 속한 하루 기록 묶음. 여러 Photo Entry를 포함할 수 있다.

## Photo Entry

Day Record 안에 포함되는 개별 사진 기록. 사진, 짧은 메모, 감정 태그, 생성 시각을 가진다.

## Local Vault

앱이 디바이스 안에 저장하는 로컬 데이터 영역. 사진, 썸네일, 메모, 감정 태그, 설정을 포함한다.

## Device-Only

서버 업로드, 계정 동기화, 외부 공유 없이 현재 디바이스에만 데이터가 존재하는 상태.

## Backup Package

사용자가 명시적으로 내보내는 백업 파일. 데이터베이스 덤프, 이미지 파일, 메타데이터를 포함할 수 있다.

## Emotion Tag

기록에 붙이는 짧은 감정 라벨. 빠른 기록 작성을 위해 칩 형태로 선택한다.

## Archive

과거 기록을 월별, 리스트, 검색, 감정 태그 필터로 다시 찾는 영역.
