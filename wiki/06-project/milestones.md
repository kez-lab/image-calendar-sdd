# Milestones

## M0: LLM Wiki Ready

Exit criteria:

- `raw/`, `wiki/`, `specs/` 구조가 있다.
- `AGENTS.md`가 LLM 운영 규칙을 정의한다.
- 제품/디자인/로컬 데이터 핵심 문서가 있다.

## M1: Design Ready

Exit criteria:

- Claude Design 결과물이 raw source로 저장된다.
- 화면별 요구사항이 wiki에 반영된다.
- 디자인 토큰과 컴포넌트 기준이 정리된다.

## M2: SDD Ready

Exit criteria:

- Spec Kit이 초기화된다.
- 첫 spec의 `spec.md`, `plan.md`, `tasks.md`가 작성된다.

## M3: MVP Prototype

Exit criteria:

- 6개 핵심 화면이 동작한다.
- 목업 또는 실제 로컬 데이터로 주요 플로우를 검증한다.

## M4: MVP Release Candidate

Exit criteria:

- 인수 기준을 통과한다.
- 로컬 저장/삭제/백업 회귀 테스트를 통과한다.
- 서버/로그인/공유 기능이 포함되지 않았음을 확인한다.
