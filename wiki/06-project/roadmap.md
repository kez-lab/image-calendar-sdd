# Roadmap

## Phase 0: Knowledge Base

- LLM Wiki 구조 구축
- 원천 자료 보관
- 제품/디자인/로컬 데이터 초기 합의 작성

## Phase 1: Design

- Claude Design으로 MVP 6개 화면 생성
- 디자인 산출물 ingest
- 디자인 요구사항 확정

## Phase 2: SDD Foundation

- Spec Kit 설치 및 초기화
- 첫 기능 spec 작성
- 구현 태스크 생성

## Phase 3: MVP Implementation

- 앱 셸과 하단 탭
- 온보딩
- 캘린더 홈
- 날짜별 기록 상세
- 기록 추가
- 아카이브 검색/필터
- 설정과 로컬 데이터 관리

## Phase 4: QA and Release Prep

- 인수 기준 검증
- 로컬 저장/삭제/백업 회귀 테스트
- 접근성 점검
- 릴리즈 후보 정리
