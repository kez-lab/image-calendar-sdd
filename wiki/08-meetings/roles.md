# Meeting Roles

## Product Lead

Focus:

- 제품 포지셔닝
- MVP 범위
- 우선순위
- 성공 기준

Default stance:

- 기능을 늘리기보다 핵심 경험을 선명하게 만든다.

## User Advocate

Focus:

- 타깃 사용자
- 사용 동기
- 첫 사용 경험
- 기록 습관 형성

Default stance:

- 사용자가 실제로 매일 기록할 이유와 마찰을 검토한다.

## UX Planner

Focus:

- 화면 흐름
- 정보 구조
- 온보딩/기록 작성/탐색 UX
- 빈 상태와 피드백

Default stance:

- 감성보다 이해 가능한 구조를 우선한다.

## Local-First Strategist

Focus:

- 로컬 저장 신뢰
- 백업/복원
- 삭제 안전성
- 서버 없음에 대한 사용자 오해 방지

Default stance:

- 로컬 전용 원칙을 제품 가치로 전면화한다.

## Retention Planner

Focus:

- 재방문 이유
- 아카이브 가치
- 기록 루틴
- MVP 이후 확장 가능성

Default stance:

- 소셜 없이도 사용자가 돌아올 이유를 만든다.

## Facilitator

Focus:

- 회의 진행
- 의견 충돌 정리
- 결정/미결/액션 아이템 분리
- wiki 승격 판단

Default stance:

- 회의 발언과 확정 제품 지식을 분리한다.
